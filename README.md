# AGV Route Lab
> **오일러·해밀턴 경로를 활용한 창고 작업 경로 계획 웹사이트**
> (Warehouse Automated Guided Vehicle Route Planning System via Eulerian & Hamiltonian Paths)

---

## 1. 프로젝트 소개

**AGV Route Lab**은 스마트 물류 창고 환경에서 단일 무인 운반 로봇(AGV: Automated Guided Vehicle)의 작업 목적에 최적화된 주행 경로를 그래프 이론을 통해 계산하고 시각화하는 전문 웹 애플리케이션입니다.

- **통로 점검 임무 (오일러 경로/회로):** 창고 바닥 청소, 소방·무선 센서 점검, 방역 등 모든 통로(변)를 정확히 한 번씩 빠짐없이 순회하는 경로를 도출합니다.
- **물품 수거·배송 임무 (해밀턴 경로/회로):** 오더 피킹(Order Picking), 부품 보급 등 모든 작업 지점(꼭짓점)을 정확히 한 번씩만 방문하는 최적의 동선을 계획합니다.

백엔드 서버나 외부 유료 API 없이 순수 웹 브라우저(HTML5, CSS3, Vanilla JS, SVG) 환경에서 구동되는 독립형 정적 웹사이트입니다.

## 2. 주요 기능

1. **이중 작업 모드 전환**
   - **통로 점검 (오일러):** 출발점 복귀 여부(회로 vs 경로) 선택 지원. 모든 통로를 1회씩 통과하므로 총이동거리는 통로 거리의 합으로 고정.
   - **물품 수거·배송 (해밀턴):** 단순 조건 만족 경로 탐색 및 전수 탐색 기반 최단거리 최적화(Shortest Cycle/Path) 지원.
2. **동적 창고 지도 및 실시간 주행 애니메이션**
   - SVG 벡터 기반 선반(Shelf) 레이아웃, 주행 통로(Corridor), 작업 지점(Node), AGV 로봇 차량 그래픽.
   - 실제 통로 선형과 설정된 통로 거리(m)에 정밀하게 비례하는 실시간 주행 시뮬레이션.
   - 주행 중 현재 위치, 다음 목적지, 누적 주행 거리, 진행률, 방문 완료 지점/통과 완료 통로 실시간 텔레메트리 연동.
   - 재생, 일시정지, 한 단계(스텝) 이동, 처음으로 복귀, 4단계 배속(0.5x, 1.0x, 2.0x, 3.5x) 제어.
3. **수학적 판정 및 근거 분석**
   - 꼭짓점 차수(Degree) 분석 및 짝수/홀수 차수 지점 시각적 하이라이트.
   - 오일러 경로 성립 불가 시 정확한 원인(홀수 차수 4개 이상, 복귀 조건 불일치, 부적절한 출발점 지정 등) 및 가능한 출발 지점 제시.
   - 해밀턴 모드에서 단순 차수나 디랙(Dirac) 정리 불만족을 이유로 불가를 단정하지 않고 철저한 탐색 수행.
   - "전수 탐색 후 경로 없음"과 "탐색 연산 한도 도달(Search Limit Reached)"을 명확히 구분.
4. **인터랙티브 지도 편집 도구 (Map Editor)**
   - 빈 공간 클릭으로 새 작업 지점 추가.
   - 지점 간 연결을 통한 양방향 통로 추가 및 중복/자기순환(Self-loop) 방지.
   - 마우스 드래그를 통한 지점 위치 이동 (지점 이동 시에도 물리적 통로 거리 설정값은 독립적으로 보존).
   - 통로 거리(m) 뱃지 클릭을 통한 양의 유한 거리 수정 모달.
   - 지도 또는 작업 조건 수정 시 이전 계산 결과 안전 초기화.
5. **사전 검증된 4대 대표 창고 시나리오 프리셋**
   - **예제 1 (모든 통로 점검):** 오일러 회로 40m 검증 경로.
   - **예제 2 (복귀 불가 점검 경로):** 홀수 차수 지점(B, D)으로 인한 열린 오일러 경로 63m 및 회로 불가 판정.
   - **예제 3 (배송 순서 최적화):** 방문 순서에 따른 해밀턴 회로 거리 비교(48m vs 최단 39m).
   - **예제 4 (임무별 가능 여부 비교):** 중앙 절점(A) 나비형 구조에서 오일러 회로는 가능하나 해밀턴 회로는 불가능한 위상학적 증명.

## 3. 그래프 모델 및 알고리즘

### 그래프 모델의 기본 가정
- **무방향 단순 연결그래프 (Undirected Simple Connected Graph):** 통로는 양방향 주행이 가능하며, 두 지점 사이의 직접 통로는 최대 1개이고 자기 자신으로 향하는 루프는 존재하지 않습니다.
- **꼭짓점(Vertex):** AGV가 필수적으로 방문해야 하는 작업 스테이션, 피킹 셀, 랙 진출입 지점.
- **변(Edge):** 두 지점을 직선 또는 전용 레일로 잇는 물리적 주행 통로.
- **가중치(Weight):** 통로의 실제 이동 거리(m, 양의 실수).
- **AGV:** 단일 차량 운행 가정. 선반이나 미연결 구역을 가로지르지 않고 오직 통로 선형을 통해서만 주행.

### 오일러 경로 알고리즘 (Eulerian Path / Circuit)
- **차수 판정:**
  - 오일러 회로 (출발점 복귀): 모든 꼭짓점의 차수가 짝수 ($odd = 0$).
  - 오일러 경로 (열린 경로): 홀수 차수 꼭짓점이 정확히 2개 ($odd = 2$). 이 경우 경로는 반드시 한 홀수 꼭짓점에서 시작하여 다른 홀수 꼭짓점에서 종료됩니다.
- **알고리즘:** **Hierholzer 알고리즘**을 무방향 멀티그래프 구조로 구현하여 $O(E)$ 선형 시간에 모든 변을 정확히 1회 통과하는 경로를 도출합니다.

### 해밀턴 경로 알고리즘 (Hamiltonian Path / Circuit)
- **탐색 방식:** 깊이 우선 탐색(DFS) 기반 백트래킹(Backtracking)과 분기한정법(Branch and Bound)을 적용.
- **최단거리 최적화:** 현재까지의 누적 거리가 기발견된 최적 경로(Best Distance) 이상일 경우 하위 트리를 가지치기(Pruning)하여 연산 속도를 극대화.
- **연산 한도 보호:** 지점 수가 많은 경우 메인 UI가 멈추지 않도록 Web Worker를 활용하며, 스텝 한도(300,000단계) 및 타임아웃(2.5초)을 두어 무한 루프를 방지합니다.

## 4. 파일 구성

```
agv-route-lab/
├── index.html            # 시맨틱 마크업, SVG 뷰포트, 컨트롤 패널, 모달
├── styles.css            # 모던 인더스트리얼 대시보드 스타일 및 반응형 레이아웃
├── app.js                # 앱 제어, 상태 관리, SVG 인터랙션, 애니메이션 루프
├── graphAlgorithms.js    # 오일러(Hierholzer) 및 해밀턴(DFS/분기한정) 알고리즘
├── examples.js           # 4가지 검증된 창고 시나리오 데이터셋
├── worker.js             # 백그라운드 연산용 Web Worker (file:// 폴백 내장)
└── README.md             # 프로젝트 매뉴얼 및 기술 문서
```

모든 자원은 상대 경로(`./`)로 참조되므로, 로컬 파일 시스템 및 GitHub Pages 하위 경로 어디서나 별도의 경로 수정 없이 원활히 작동합니다.

## 5. 실행 방법

### 로컬 브라우저에서 바로 열기
1. 프로젝트 폴더 내 `index.html` 파일을 더블 클릭하거나, Chrome, Edge, Safari, Firefox 등 웹 브라우저 창으로 드래그 앤 드롭합니다.
2. 추가 설치 프로그램(Node.js, Python, 웹 서버 등) 없이 100% 즉시 구동됩니다.

*(선택 사항)* 로컬 개발 서버를 사용하려면:
```bash
# Python 내장 서버 사용 시
python -m http.server 8080

# Node npx 사용 시
npx serve .
```
브라우저에서 `http://localhost:8080`으로 접속합니다.

## 6. GitHub 업로드 및 GitHub Pages 배포 방법

본 프로젝트의 모든 파일(`index.html`, `styles.css`, `app.js`, `graphAlgorithms.js`, `examples.js`, `worker.js`, `README.md`)을 그대로 GitHub 레포지토리에 커밋하면 바로 배포할 수 있습니다.

### Git 커밋 및 푸시
```bash
git init
git add .
git commit -m "feat: initial commit of AGV Route Lab"
git branch -M main
git remote add origin https://github.com/<사용자아이디>/<저장소이름>.git
git push -u origin main
```

### GitHub Pages 배포 설정
1. GitHub 저장소의 상단 메뉴에서 **Settings** 클릭
2. 좌측 메뉴의 **Pages** 클릭
3. **Build and deployment** > **Branch**에서 `main` 브랜치 및 `/(root)` 선택 후 **Save** 클릭
4. 1~2분 후 `https://<사용자아이디>.github.io/<저장소이름>/` 주소로 전 세계에 정적 배포가 완료됩니다.
